# 单场戏创作与修订

写作顺序：确定功能 → 建立当场目标和阻碍 → 组织因果节拍 → 写可表演正文 → 以正文证据审查 → 修订后派生分镜与提示词。不要只填表而不改变戏。

## 1. 先判断场次功能

- 冲突推进场：以“接下来会怎样”吸引观众，重点检查目标、阻碍、节拍、价值变化和合理转折。
- 揭示／悬念场：检查观众原先的问题、逐步可见的线索、知情差的变化和兑现，避免一直藏答案却不提供进展。
- 过渡／余波场：检查承接什么情绪、时间或行动，给下一场建立什么必要状态；可以很短，不强迫另起冲突和转折。
- 奇观／抒情场：检查具体视听吸引点、人物体验及其在全片的位置，避免仅用“很美、很震撼”宣告效果。

允许混合功能、无对白和独角戏；阻碍可以来自环境、制度或内心矛盾。内心阻碍用可观察的迟疑、选择及后果呈现，不凭空增设一个吵架对手。不要用“过渡场”标签豁免承担核心事件的长篇空谈。没有独立作用的场次应删并。

## 2. 写作时执行

1. **明确谁要什么。** 写成“人物此刻要让谁做什么／得到什么／阻止什么”；判断成功、失败或暂时僵持的标准。目标可隐藏在潜台词里，不必让人物亲口宣布。必要时注明为何现在、失败的小代价，不强迫每场生死攸关。
2. **让阻碍有效。** 对手有自己的利益、认知和可用手段；环境有已建立的限制。阻碍必须使原计划难以继续，不能只嘴上说“不”。
3. **组织节拍。** 用工作笔记“主动方＋行动动词＋对象 → 阻碍的具体反应 → 改变了什么 → 因此下一步”推演。动作可为请求、讨价还价、回避或沉默，不仅是肢体动作；反应必须受到前一行动影响。一个节拍可跨多句对白／多镜，短暂局部成功可以制造更深代价。
4. **赋予对白目的。** 问这句话要改变对方哪项行为、判断或关系。背景信息通过试探、掩饰、证明、交换等当场需要出现，避免双方互说早已知道的信息。删掉没有人物刻画、情绪、节奏或因果作用的台词；允许有明确作用的闲聊、停顿和表演，不要求每句都是剧情机关。
5. **推进而非循环。** 下一次努力应针对前一次失败改变策略，或使信息、筹码、关系、时间压力、代价、可选路径发生变化。可以缓和、停顿、让步或反复试探，但重复必须产生累积作用。相邻两拍若只是“求—拒绝”的同义改写，合并或重写，不靠固定拍数补长度。
6. **按需要转换主动权。** 被动方可以提出条件、夺走资源或迫使对方回答，让原主动方作选择。检查转换的动作和动机；不强制每场转换、等量分配台词，或把进攻理解成恶意。
7. **检验价值变化。** 选择观众关心的具体价值，如安全、信任、自由、尊严、归属、资源。比较同一人物、同一维度的场前／场后处境，用行为或事实证明“无→有、稳定→受威胁、疏离→暂时信任”等。可以负→更负、得物失信等混合变化，不强制正负翻面。只换地点、表情或旁白说“成长了”不够。
8. **让转折有来源。** 先确定观众预期，再设计改变结果或理解的行动／揭示。回溯必要条件何时可见、角色如何知道并利用它，以及前面的冲突为何促使此刻触发。铺垫要足以支持结果，也别提前把答案解释完。若新增末尾救星才成立，补建条件或改成角色已有选择的后果。
9. **在有效位置结束。** 结果明确、处境改变或新问题建立后即可切走。观众可推知的交代允许省略；若省略，注明下一场用何行为／状态兑现，不省掉关键选择或新后果。无固定起承转合比例，不把“合必须再转一次”作为硬规则。

## 3. 审查与修复标准

结论使用“通过／需修订／不适用（理由）”，每项给出正文位置或具体动作，不以总分掩盖因果漏洞。

| 检查 | 通过证据 | 失败时修复 |
| --- | --- | --- |
| 目标与阻碍 | 能说清当场争取的结果，以及哪次反应令其受阻 | 把抽象愿望改成可行动目标，赋予阻碍有效手段 |
| 动作—反应因果 | 下一行动能用“因为刚才……所以……”接上 | 删掉无关联回合或补上反应及新选择 |
| 对白目的 | 关键台词有对象、行动目的和对方反应 | 将背景说明改成争取／隐瞒／交换所需的信息 |
| 冲突进展 | 策略、筹码、代价或选择确实改变；重复有累积 | 合并同义争执，改变做法及其后果 |
| 攻防转换 | 若有，指出谁以什么行动夺取主动；若无，不扣分 | 补动机和迫使对方反应的实际行动，或删无用互换 |
| 价值变化 | 同一维度的前后状态和可见证据；功能场另查实际作用 | 让事件留下结果，或删并无作用场次 |
| 转折可信 | 铺垫→触发→后果均在故事中；无新增万能信息 | 前移必要条件、让人物利用既有资源或改写结果 |
| 收尾与下游 | 结束点合理；省略有兑现位置；镜头／提示词保留证据 | 删重复收尾、补兑现，同步修改派生内容 |

再做两项反事实检查：删除关键反应，下一步是否仍原样发生？若是，节拍可能没有因果。删除铺垫，结局是否仍仅靠作者宣布？若是，所谓铺垫可能只是装饰。此检查用于定位问题，不证明艺术效果。
